# 自然探究實驗室｜康軒版國小五上自然 v2.0.0

純靜態網站，可直接部署到 GitHub Pages，不需要 npm、Vite 或編譯。

## 部署
把本資料夾所有檔案（包含 `.nojekyll`）放在 GitHub Pages 使用的 branch 根目錄。

GitHub → Settings → Pages → Build and deployment：
- Source: Deploy from a branch
- Branch: `deploy`（或你指定的發布 branch）
- Folder: `/(root)`

Windows 可先雙擊 `VERIFY_DEPLOY.bat` 做必要檔案、JavaScript 語法與 v2.0 資料結構檢查，再使用 `PUSH_DEPLOY.bat`。

## v2.0 大改版重點
- 首頁維持「只看目前單元」；不顯示整學期大地圖。
- 第一、二單元六課改寫成「生活現場 → 科學破案 → 實驗環 → 找證據 → 一句記住 → 6題挑戰 → 救援」。
- 六課共有 45 個細部概念小節，改成折疊式破案卡；一次只展開一張，避免文字牆。
- 前兩單元每課 30 題，共 180 題；整站分課題庫共 300 題。
- 第一單元涵蓋牙齒／鳥嘴、內溫外溫、遷徙、自我保護、蟻蜂分工、蜜蜂舞蹈、獼猴母系社會、繁殖與遺傳等。
- 第二單元涵蓋噪音與分貝、振幅／頻率／音色、弦管打擊、音箱、折射、海市蜃樓、凸凹透鏡、近視、虹霓、泡泡薄膜、光聲速度與水族箱視位置等。
- 前兩單元新增 19 個安全「科學實驗環」小任務；不鼓勵以放大鏡點燃紙張或火柴。
- U1/U2 連連看題庫增為 33／31 對；分類情境增為 22／21 題；科學島直接抽取 90 題／單元的大題庫。
- 第一次段考 A／B 全面重出：各 39 個作答項目、100 分、40 分鐘，混合是非、單選、配合、複選、圖像／實驗與填充。
- 期中卷型參考公開康軒第 1～2 單元學校定期評量，只分析題型與能力，不複製原題。
- 第二次段考 A／B 維持第三、四單元既有學校卷型配置，各 34 個作答項目、100 分、40 分鐘。
- 每個主要內容、實驗說明與考題保留喇叭朗讀。

## 使用方式
- 不設登入牆；開站即可學習。
- 右上角只提供「研究員名字」簡易設定，不需帳號、密碼或 PIN。
- 進度、星星、錯題、A／B 卷成績存在該瀏覽器 `localStorage`。
- 朗讀使用裝置內建 Web Speech 中文語音；不同手機／電腦的人聲略有差異。
