# 自然探究實驗室｜康軒版國小五上自然 v1.1.0

純靜態網站，可直接部署到 GitHub Pages，不需要 npm、Vite 或編譯。

## 部署
把本資料夾所有檔案（包含 `.nojekyll`）放在 GitHub Pages 使用的 branch 根目錄。

GitHub → Settings → Pages → Build and deployment：
- Source: Deploy from a branch
- Branch: `deploy`（或你指定的發布 branch）
- Folder: `/(root)`

Windows 可先雙擊 `VERIFY_DEPLOY.bat` 做語法與必要檔案檢查，再使用 `PUSH_DEPLOY.bat`。

## 更新辨識
左上角應顯示：
- `國小五上・自然科・康軒版`

## v1.1 重點
- 首頁取消「整學期地圖」，只顯示目前單元與 3 個活動。
- 12 課擴成完整小節整理，含例子、易錯點、記憶法與人聲朗讀。
- 240 題分課題庫；每次只抽 6 題分級挑戰。
- 實驗室為獨立工作台，不再跳回課程同一段內容。
- 每單元三種遊戲：雙欄連連看、快速分類、24 格科學島。
- 每單元 18 對配對庫、12 題分類庫、60 題以上科學島題池。
- 期中 A／B、期末 A／B 各 34 個作答項目、100 分、40 分鐘，混合多種學校卷型。

## 使用方式
- 不設登入牆；開站即可學習。
- 右上角只提供「研究員名字」簡易設定，不需帳號、密碼或 PIN。
- 進度、星星、錯題、A／B 卷成績存在該瀏覽器 `localStorage`。
- 朗讀使用裝置內建 Web Speech 中文語音；不同手機／電腦的人聲略有差異。
